# Windows Troubleshooting & Ticket Simulation Lab

Hands-on Help Desk lab focused on troubleshooting common Windows support issues using VirtualBox and Windows 11.

## Purpose

This project documents simulated IT Support tickets with real troubleshooting steps, screenshots, and resolution notes.

- Windows 11 VM
- VirtualBox
- Local Windows Accounts
- Local Security Policy
- Computer Management
